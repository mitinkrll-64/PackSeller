# Релиз PackSeller

## Состав релиза
```
PackSeller/
  PackSeller.dll
  RE_Kenshi.json        формат — по примеру KenshiLib_Examples [TO VERIFY]
  PackSeller.mod        файл мода, если нужен для лаунчера [TO VERIFY: нужен ли]
  PackSeller.config     конфиг по умолчанию (формат — из api-notes)
  README.txt            установка, требования, настройки, известные ограничения
  LICENSE               GPLv3
  CHANGELOG.txt
```
Структура и имена файлов сверяются с примерами и с требованиями лаунчера Kenshi. Не придумывать формат `RE_Kenshi.json`.

## Перед выпуском
1. Пройден `docs/test-plan.md`; блокирующих багов нет; результат тестов приложен к changelog.
2. Версии в README, DLL и changelog совпадают; указаны версия игры, RE_Kenshi, KenshiLib.
3. Релизная сборка (Release), без отладочных символов и без отладочного лога по умолчанию.
4. Лицензия GPLv3, ссылки на исходники и на KenshiLib/RE_Kenshi.
5. Исходники опубликованы или приложены (требование GPLv3 при распространении).

## README (русский и английский)
- Что делает мод, скриншоты (если есть).
- Требования: Kenshi (версии), RE_Kenshi (версия), порядок загрузки.
- Установка: куда положить, как включить в лаунчере.
- Использование: открыть инвентарь вьючного животного → «Торговцы» → выбрать торговца → «Продать».
- Настройки: радиус, таймаут, отладочный лог.
- Известные ограничения версии 0.1: одно животное; нет отмены кнопкой; животное может погибнуть в дороге; только городские торговцы.
- Совместимость и удаление мода (поведение сейвов).
- Как сообщать об ошибках (что приложить: версия, шаги, `RE_Kenshi_log.txt`).
