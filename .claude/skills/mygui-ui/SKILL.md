# UI PackSeller (MyGUI)

## Основа
Пример KenshiLib_Examples «Kill Button» показывает, как безопасно создавать элементы MyGUI. UI создаётся и изменяется только из главного потока игры. Конкретные классы окна инвентаря и макеты — из `docs/api-notes.md` (вопрос 1). Не придумывать имена виджетов.

## Что нужно сделать
1. **Кнопка «Торговцы»** в окне инвентаря вьючного животного, под кнопкой конечностей. Появляется только когда инвентарь принадлежит вьючному животному и у него нет активного приказа (в версии 0.1 приказ нельзя отменить кнопкой, поэтому при активном приказе кнопка неактивна или скрыта).
2. **Модальное окно** со списком торговцев:
   - строка: имя торговца, город, расстояние, деньги, кнопка «Продать»;
   - переключатель сортировки: расстояние (по умолчанию), деньги, город;
   - пометка у города, если фракция враждебна игроку (текст/цвет; не полагаться только на цвет);
   - пустое состояние: «Нет подходящих торговцев поблизости»;
   - закрытие по кнопке и по Esc; окно не должно блокировать игру навсегда.
3. **Положение и размеры** под разные разрешения; не перекрывать критичные элементы интерфейса; проверить на масштабах интерфейса игры `[TO VERIFY]`.

## Безопасность UI
- Все указатели на виджеты проверять перед обращением; при закрытии окна и при выгрузке инвентаря животного уничтожать свои виджеты и отписываться от событий.
- Окно инвентаря может быть пересоздано игрой: держать связь с ним через механизм, подтверждённый в api-notes, и не хранить «висячие» указатели.
- Конфликты с модами, которые тоже меняют окно инвентаря (например, поиск в инвентаре): не перезаписывать чужие виджеты, использовать уникальные имена с префиксом `PackSeller_`, проверить расположение рядом с чужими элементами.
- Клик «Продать» только ставит приказ в конечный автомат (`pack-animal-fsm`), сам ничего не делает с предметами.

## Локализация
- Русский по умолчанию; тексты вынести в одну таблицу строк (ключ → русский/английский).
- Кириллица в MyGUI: проверить шрифт игры; если символы не отображаются, найти способ, как это делают другие моды (например, Organize the Inventory поддерживает кириллицу) `[TO VERIFY]`.
- Кодировка файлов с текстами: UTF-8; проверить, как её читает плагин.

## Проверка
Скриншотов из игры у ИИ нет без участия пользователя: UI-чек-лист в `docs/test-plan.md` выполняет пользователь и присылает скриншоты. До этого этап не считается принятым.
